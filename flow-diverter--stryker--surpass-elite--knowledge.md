# Surpass Elite Flow Diverter

**Manufacturer:** Stryker Neurovascular
**Category:** Flow diverter
**PMA:** P170024 | Class 3 | 2025-02-12

## What It Is

Third-generation self-expanding braided flow diverter for intracranial aneurysm treatment. Successor to the Surpass Evolve. Features 64-wire pure cobalt-chromium construction for high mesh density maximized for flow diversion, with enhanced material strength for a durable braid that resists fatigue.

Incorporates the BioStealth Surface, a phosphorylcholine surface modification that reduces thrombin generation by 91% compared to an unmodified device in bench testing (n=min 9 stent segments, Stryker data on file).

## Compatible With

- Excelsior XT-27 Microcatheter (delivery catheter)

## Use Notes

- BioStealth Surface is a phosphorylcholine surface modification designed to reduce thrombogenicity (plasma proteins interact in a more natural state, limiting clot formation)
- Higher braid angle compared to Surpass Evolve for opening with less manipulation
- Higher durometer resheath pad allows confident resheathing without compromising proximal opening
- 64-wire construction provides higher mesh density than most competing flow diverters

## Key Differences vs Competitors

- **Wire Count**: Surpass Elite uses 64 CoCr wires, the highest braid wire count among major flow diverters. Pipeline Flex uses a variable count (platinum/tungsten + CoCrNi). Silk Vista uses 48 DFT wires. FRED X uses a dual-layer braid.
- **Surface Technology**: BioStealth Surface (phosphorylcholine) with 91% thrombin reduction in bench testing. Pipeline Flex also uses phosphorylcholine (Shield Technology). FRED X uses a different approach (nanoscale covalent X Technology). Silk Vista has no surface modification.
- **Delivery Catheter**: Surpass Elite is delivered through Excelsior XT-27 (0.027"). FRED X uses Headway 21/27 depending on size. Pipeline Flex uses Phenom 17/21/27.
- **Resheathing**: Surpass Elite features a higher durometer resheath pad specifically optimized for resheathing confidence. FRED X and Pipeline Flex also support resheathing.
- **Successor Design**: Surpass Elite is a direct successor to Surpass Evolve with larger/longer sizes, higher braid angle, and stronger material. The Streamline and Evolve are earlier-generation Surpass devices.
