# Benchmark Intracranial Access System

**Manufacturer:** Penumbra, Inc.
**Category:** Microcatheter (Guide Catheter / Intracranial Access)
**510(k):** K212838 (May 27, 2022)
**Classification:** Catheter, Percutaneous, Neurovasculature; Class II; 21 CFR 870.1250; Product Codes QJP, DQY

---

## What It Is

Two-component intracranial access system designed to aid the physician in reaching target vasculature during interventional procedures. The system consists of a Benchmark Delivery Catheter (guide catheter) and an optional Penumbra 5F Select Catheter used coaxially to facilitate navigation.

Key design features:
- Delivery Catheter: coil-reinforced, single-lumen guide catheter with hydrophilic distal coating; 6F profile; 0.071" inner diameter; compatible with off-the-shelf accessories
- 5F Select Catheter: braid-reinforced, variable-stiffness diagnostic/support catheter; available in multiple tip shapes (SIM, H1, BER); used coaxially inside the Delivery Catheter for target vessel selection
- Both components carry a radiopaque distal end for fluoroscopic visualization
- Luer hub on proximal end of each component
- Available packaged as standalone Delivery Catheter or as a combined Delivery Catheter + 5F Select Catheter kit
- Cleared with IFU updates specifically addressing radial access use (the primary change from the prior-generation Benchmark system)
- Sterile, non-pyrogenic, single-use only; ethylene oxide sterilized

The Benchmark system is Penumbra's intracranial guide catheter platform. The 2022 clearance (K212838) adds radial access guidance to the IFU; the technological characteristics are otherwise identical to the prior Benchmark clearance (K142321).

## Indications

The Benchmark Intracranial Access System is indicated for the introduction of interventional devices into the peripheral, coronary, and neuro vasculature.

---

## Use Notes

- The 5F Select Catheter is used coaxially inside the Delivery Catheter to assist in target vessel selection, then withdrawn once the Delivery Catheter is positioned
- IFU includes specific instructions for radial artery access approach in addition to standard femoral access
- Compatible with off-the-shelf accessories (guidewires, microcatheters, rotating hemostasis valves)
- Single use only; do not reprocess or resterilize

## Key Differences vs Competitors

- **Size and inner diameter**: The Benchmark Intracranial Access System (6F, 0.071" ID) is smaller than the larger-bore Penumbra BMX81 (7F, 0.081" ID) and BMX96 (8F, 0.096" ID) systems, and has a smaller inner diameter than the Piraeus 87 NeuGlide (0.087" ID) and 93 NeuFlex (0.093" ID) catheters, which are both 6F-compatible. The Stryker Broadway 8 Catheter size is not specified.
- **System components and design**: Unlike the single-lumen Piraeus catheters (87 NeuGlide, 93 NeuFlex) and the Stryker AXS Lift™/Broadway catheters, the Benchmark system is a two-component coaxial system (Delivery Catheter + optional 5F Select Catheter), similar in concept to the other Penumbra Benchmark systems (BMX81, BMX96). The Medtronic Echelon Microcatheter is a distinct single-lumen microcatheter for distal delivery, not a guide/access system.
- **Specific use and compatibility**: The Benchmark system's IFU includes specific instructions for radial artery access, a detail not specified for the other devices listed. It is compatible with off-the-shelf accessories and uses a 5F Select Catheter coaxially, whereas the Piraeus catheters are noted for use *with* support/diagnostic catheters, and the Medtronic Echelon is compatible with specific embolic systems and guidewires (0.014" or smaller).
