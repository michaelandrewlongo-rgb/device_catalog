# Everest Deformity Spinal System

**Manufacturer:** Stryker
**Category:** Pedicle screw system / Deformity

## What It Is

Top-loading pedicle screw system designed for complex spinal deformity correction. Mixed-metal (Ti/CoCr) tulip minimizes head splay with improved biomechanical performance vs all-titanium screws. Dual-lead thread pattern for faster insertion. Tapered distal third for increased pullout strength. Modified square thread set screw design facilitates introduction and locking. Accepts 5.5 mm and 6.0 mm titanium and cobalt-chrome rods.

## Sizing/Specs

- Rod diameters: 5.5 mm and 6.0 mm
- Rod materials: Titanium and cobalt-chrome
- Mixed-metal tulip (Ti/CoCr)
- Multiple screw types and lengths available (refer to surgical technique guide)

## Indications

Complex spinal deformity correction (scoliosis, kyphosis, sagittal imbalance).

## Compatible With

- BaseCamp deformity rod reducer (sequential reduction and correction; allows placement of multiple tubes for sequential reduction)
- Spine Guidance 5 (navigation)
- Mako Spine with Copilot robotic features

## Use Notes

BaseCamp rod reducer allows sequential placement of multiple tubes for progressive deformity reduction. Mixed-metal tulip is a differentiating feature for high-demand deformity constructs. Now sold by VB Spine.

## Key Differences vs Competitors

- The Everest Deformity Spinal System features a mixed-metal (Ti/CoCr) tulip, which is a differentiating feature for high-demand deformity constructs, unlike other Stryker systems like ES2 MIS, Serrato, and Xia 3 which do not specify mixed-metal tulips.
- Everest accepts both 5.5 mm and 6.0 mm titanium and cobalt-chrome rods, similar to CD HORIZON SOLERA and CREO 5.5 (DLX rod), but unlike ES2 MIS which accepts only titanium rods.
- Everest is specifically designed for complex spinal deformity correction (scoliosis, kyphosis, sagittal imbalance), whereas ES2 MIS is for MIS thoracolumbar fixation and Serrato for general thoracolumbar fixation.
- The Everest system is compatible with the BaseCamp deformity rod reducer for sequential reduction and correction, a feature not explicitly mentioned for other pedicle screw systems listed.
- Unlike the Tritanium TL Curved Posterior Lumbar Cage, which is an interbody cage, Everest is a pedicle screw system for posterior fixation.
