# ExcelsiusGPS Robotic Navigation Platform

**Manufacturer:** Globus Medical
**Category:** Navigation system

## What It Is

Ecosystem of robotic navigation: ExcelsiusGPS (robotic guidance), Excelsius3D (intraop imaging), ExcelsiusHub (data). NVM5 neuromonitoring integrates nerve avoidance, monitoring, computer-assisted rod bending, angular assessment.

## Key Differences vs Competitors

- **System type**: ExcelsiusGPS is a robotic navigation platform with integrated intraoperative imaging (Excelsius3D) and data management (ExcelsiusHub), while competitors include instrument-only navigation platforms (ChoiceSpine NavLock), robotic platforms integrated with third-party navigation (Mazor X Stealth Edition), standalone imaging systems (O-arm), and software-based navigation systems (StealthStation S8, Q Guidance, SpineMap 3D).
- **Core technology**: ExcelsiusGPS uses robotic guidance with integrated neuromonitoring (NVM5) for nerve avoidance and computer-assisted rod bending, whereas competitors use optical tracking of instruments (ChoiceSpine NavLock, StealthStation S8, Q Guidance, SpineMap 3D), robotic arm guidance with separate navigation integration (Mazor X Stealth Edition), or cone-beam CT imaging (O-arm).
- **Compatibility**: ExcelsiusGPS is compatible with CREO and Reline fixation systems and Bendini rod bending, while competitors are compatible with Medtronic navigation and implants (ChoiceSpine NavLock, Mazor X Stealth Edition, O-arm), Stryker navigation and implants (Q Guidance, SpineMap 3D), or Medtronic cranial applications (StealthStation S8).
- **Workflow integration**: ExcelsiusGPS provides an integrated ecosystem (robotics, imaging, data) within a single platform, while most competitors require integration of separate systems (e.g., Mazor X requires StealthStation and O-arm; ChoiceSpine NavLock requires StealthStation navigation).
