# iFuse INTRA X

**Manufacturer:** Si-Bone
**Category:** Sacroiliac Fusion

## What It Is

Allograft implant for intra-articular SI joint stabilization and fusion. Percutaneous delivery through a single needle-like incision. Sterile single-use instrument set. Designed for reproducible intra-articular placement.

## Use Notes

Percutaneous delivery (single needle-like incision) distinguishes from iFuse INTRA. Sterile single-use instrument set promotes procedural efficiency. FEA biomechanics testing showed favorable results vs competitor rectangular ridged allograft (Technical Study 301310-TS).

## Key Differences vs Competitors

- **Material/Implant Type**: iFuse INTRA X is an allograft implant, distinguishing it from titanium implants like iFuse Implant System (triangular titanium), iFuse TORQ (3D-printed porous titanium), iFuse TORQ TNT (3D-printed porous titanium), and iFuse Bedrock Granite (titanium with porous surface). It shares the allograft material with iFuse INTRA.
- **Delivery/Incision**: Uses percutaneous delivery through a single needle-like incision, which is noted as a distinction from iFuse INTRA (specific incision difference not specified for iFuse INTRA). Other devices (iFuse Implant System, iFuse TORQ, iFuse TORQ TNT, iFuse Bedrock Granite) have delivery/incision methods not specified.
- **Indications**: Specifically for intra-articular SI joint stabilization and fusion, similar to iFuse INTRA and iFuse TORQ (both minimally invasive SI joint fusion). Differs from iFuse Bedrock Granite (spinopelvic fixation in adult deformity/revision) and iFuse TORQ TNT (pelvic fragility fractures, sacral insufficiency fractures).
- **Key Feature/Testing**: Sterile single-use instrument set promotes procedural efficiency; FEA biomechanics testing showed favorable results vs competitor rectangular ridged allograft (Technical Study 301310-TS). iFuse INTRA shares the same biomechanical testing reference vs competitor rectangular ridged allograft. Other devices have different testing/features: iFuse TORQ (sheep model histology, STACI trial), iFuse TORQ TNT (150% stronger in bending, FDA Breakthrough Designation for pelvic fractures), iFuse Bedrock Granite (FDA Breakthrough Designation, addresses 24% lumbopelvic fixation failure rate).
