# Route 92 Medical Full Length 054 Reperfusion System and Aspiration Tubing Set

**Manufacturer:** Route 92 Medical, Inc.
**Category:** Aspiration Catheter

## What It Is

Two-catheter aspiration reperfusion system for acute ischemic stroke, consisting of: (1) the Aspiration Catheter, a single-lumen, coil-reinforced, variable-stiffness catheter; (2) the Tenzing 7 Delivery Catheter, a single-lumen variable-stiffness catheter; and (3) the Route 92 Medical Aspiration Tubing Set. Both catheters are hydrophilically coated, supplied sterile and non-pyrogenic, and intended for single use. The Aspiration Tubing Set is high-pressure tubing with an on/off switch for flow control, a suction connector for aspiration pump canister attachment, and a luer fitting for catheter connection. The aspiration source is a compatible aspiration pump connected via the tubing set with a commercially available canister. 510(k) K233329, cleared April 2024. The FDA device name on this clearance is the Full Length 054 system; the catalog filename reflects this clearance. A predicate 070 system (K223530/K222743) also exists. Note: encoding artifacts in the source (replacement character) appear in some vessel descriptions; these reflect the M1/M2 dash in the original FDA document.

## Indications

The Route 92 Medical Full Length 054 Reperfusion System and Aspiration Tubing Set is indicated for use in the revascularization of patients with acute ischemic stroke secondary to intracranial large vessel occlusive disease (within the internal carotid, middle cerebral - M1 and M2 segments, basilar, and vertebral arteries) within 8 hours of symptom onset. Patients who are ineligible for intravenous tissue plasminogen activator (IV t-PA) or who failed IV t-PA therapy are candidates for treatment.

## Use Notes

- System requires a commercially available vacuum source (aspiration pump) with compatible canister; not included
- On/off switch on the tubing set controls vacuum application
- Both catheters are single use, supplied sterile and non-pyrogenic
- Tenzing 7 Delivery Catheter is a coaxial delivery catheter used with the Aspiration Catheter; not a standalone guide catheter

## Key Differences vs Competitors

- **Catheter system design**: The Full Length 054 system includes two catheters (Aspiration Catheter and Tenzing 7 Delivery Catheter) used coaxially, while competitors like the APRO Aspiration Catheter, AXS Catalyst 7, and 072 Aspiration System use single aspiration catheters. The HiPoint system also uses a coaxial design but with a different catheter construction (proximal control wire vs. coil-reinforced).
- **Aspiration catheter inner diameter**: The Full Length 054 Aspiration Catheter has 0.070" ID, which is larger than the AXS Catalyst 7 (0.068") and APRO 55 (not specified), but smaller than the HiPoint 70 Aspiration Catheter (0.071") and APRO 70 (not specified). The 072 Aspiration System ID is not specified.
- **Indications scope**: The Full Length 054 system is indicated for M1 and M2 segments, basilar, and vertebral arteries within 8 hours, matching the Artemis/Penumbra and AXS Catalyst indications. The HiPoint system is indicated only for M1 segment (not M2, basilar, or vertebral), while the 072 Aspiration System and APRO indications are not fully specified.
- **Delivery catheter specifications**: The Tenzing 7 Delivery Catheter has 0.019" ID and 0.062" OD, while delivery catheter specs for other systems (HiPoint, APRO, AXS Catalyst, 072) are not specified.
- **Tubing set specifications**: The Full Length 054 Aspiration Tubing Set has 0.110" ID and 112" length, while the APRO's Alembic tubing has 0.110" ID and 100" proximal length (plus 7" distal), and tubing specs for other systems are not specified.
