# Revere Addition Revision Fixation System -- Globus Medical

## What It Is

A revision-specific posterior spinal fixation system that allows extension of an existing Globus construct (REVERE, CREO, BEACON, or PROTEX) without removing the existing instrumentation. Instead of taking out prior hardware and replacing everything, the system uses a family of specialized clamps that attach directly to the existing rod or screw heads, with integrated extension rods that connect to new pedicle screws above or below the original construct. The critical design feature is the clamp-to-rod junction (the "radius"), which is mechanically stronger than a typical side-loading revision connector. The system uses the REVERE non-threaded locking cap, which captures the rod with a 90-degree rotation (no cross-threading risk), then locks with a set screw. Compatible with 5.5-6.5mm rods.

## Sizing / Specs

**Rod compatibility:** 5.5mm to 6.5mm diameter rods

**Connector types:**

| Connector | Coupling | Key Feature |
|---|---|---|
| In-Line Extension Clamp | Direct in-line to existing rod | Integrated extension rod; best for tight spaces and smaller patients |
| Offset Extension Clamp | 7mm lateral offset from existing rod | Integrated extension rod; use when in-line alignment is not achievable |
| "U" Extension Clamp | Short run-on-rod with built-in lordotic curve | Best for lumbar connections; can offset medially or laterally |
| "Y" Clamp | Short run-on-rod on each side of a screw | Offsets medially or laterally to meet anatomy |
| Parallel Connector Clamp | Connects two parallel rods | For linking adjacent rod constructs |
| Rod-to-Rod Clamp | Connects rod to rod | For bridging between constructs |

**Locking mechanism:** Non-threaded locking cap with 90-degree rotation capture, then set screw final tightening

**System compatibility:** REVERE, CREO, BEACON, PROTEX (all Globus Medical posterior systems)

**RESCUE Implants:** The extension clamps are part of the RESCUE implant family within the REVERE system

## Indications

- Proximal junctional kyphosis (PJK) or failure requiring cranial extension of an existing construct
- Distal junctional failure requiring caudal extension (e.g., extending to sacrum/pelvis)
- Adjacent segment disease requiring additional levels of fixation above or below prior fusion
- Rod fracture or loosening at the proximal or distal end of a long construct
- Pseudarthrosis at the end of a construct requiring extension and revision grafting
- Any revision scenario where the existing Globus hardware is intact and does not need removal

**Key advantage:** Avoids a full exposure of the entire prior construct. Only the junction zone and the new extension levels need to be exposed, reducing scar tissue dissection, blood loss, and operative time.

## Contraindications

- Active infection at the operative site
- Severe osteoporosis or osteopenia that would compromise implant fixation
- Patient conditions precluding benefit of spinal fixation (e.g., morbid obesity, pregnancy, mental illness, substance abuse affecting compliance)
- Inadequate tissue coverage of the implant
- Known allergy to titanium or cobalt-chromium alloy
- Any condition that would compromise the ability of the implant to provide stability
- Existing hardware is NOT a Globus system (REVERE, CREO, BEACON, or PROTEX); this system is not compatible with other manufacturers' implants

## Use Notes

- This is a revision-only system; it is not used for primary instrumentation
- The main advantage is avoiding full-length revision exposure, reducing blood loss and operative time
- Confirm the existing hardware is a compatible Globus system before the case (check prior operative reports and implant records)
- The non-threaded locking cap eliminates cross-threading, which is particularly valuable in revision cases where debris contaminates screw heads
- In-Line Extension Clamp provides the strongest junction; use Offset only when anatomy prevents in-line alignment
- The "U" Extension Clamp is ideal for lumbosacral transitions where lordotic curvature must be accommodated
- Rod diameter of the existing construct must be confirmed preoperatively (most Globus systems use 5.5mm; some deformity constructs use 6.0 or 6.35mm)

## Use Step-by-Step

1. **Preoperative planning.** Review imaging to identify the existing hardware system (must be Globus REVERE, CREO, BEACON, or PROTEX). Plan the extension direction (cranial, caudal, or both). Determine which clamp type best fits the anatomy: In-Line for straight extensions, Offset for cases where the new rod path cannot align with the old, "U" for lumbar lordotic transitions, "Y" when branching from a single screw head.

2. **Position and expose.** Prone positioning. Expose only the junction zone of the existing construct (the most cranial or caudal screw/rod) and the new levels to be instrumented. Avoid unnecessary exposure of the entire prior construct.

3. **Expose the existing rod at the junction.** Clear soft tissue and scar from the terminal portion of the existing rod or the most proximal/distal screw head where the clamp will attach. Only enough rod needs to be exposed to seat the clamp.

4. **Select and seat the appropriate clamp.** Choose the clamp type based on anatomy:
   - **In-Line Extension Clamp:** Slide onto the exposed rod in line with the existing construct. The integrated rod extends cranially or caudally.
   - **Offset Extension Clamp:** Attach to the existing rod with 7mm of lateral offset. Useful when the new screw trajectory does not align with the old rod path.
   - **U Extension Clamp:** Attach for lumbar connections where a short lordotic curve transition is needed. Orient medially or laterally as anatomy requires.
   - **Y Clamp:** Attach at a screw head to create extension rods on both sides.

5. **Place new pedicle screws.** Instrument the new levels (above or below the existing construct) using standard technique with REVERE-compatible pedicle screws.

6. **Connect the extension rod.** The integrated rod from the clamp is captured into the new pedicle screw heads. Use the REVERE non-threaded locking cap: insert the cap into the screw head, rotate 90 degrees to capture the rod, then tighten the set screw to lock.

7. **Final tighten all connections.** Secure the clamp-to-rod junction and all new locking caps. Verify alignment and construct rigidity.

8. **Confirm with fluoroscopy.** AP and lateral views to verify screw position, rod alignment, and clamp seating.

## Pearls / Troubleshooting

- **Identify the existing system before the case.** This system is ONLY compatible with Globus REVERE, CREO, BEACON, and PROTEX hardware. It will not work with other manufacturers' rods or screw heads. Verify the prior implant record.
- **Minimize exposure.** The main advantage of this system is avoiding a full-length revision exposure. Resist the temptation to expose the entire construct "just in case." Only expose the junction zone and new levels.
- **In-Line vs. Offset decision:** Use In-Line whenever the rod paths will align. The In-Line clamp creates a mechanically stronger junction. Use Offset only when the new screw trajectory or anatomy prevents in-line alignment (7mm of offset is available).
- **The "U" clamp is ideal for lumbosacral transitions** where you need a short lordotic curve between the existing construct and the new extension. It offsets medially or laterally depending on orientation.
- **The non-threaded locking cap eliminates cross-threading**, which is a common frustration in revision cases where tissue, blood, and debris contaminate the screw heads. The 90-degree rotation capture is much more reliable intraoperatively.
- **"The strength is in the radius."** The clamp-to-rod junction radius in this system is engineered to be stronger than standard side-loading connectors. This matters at the junction zone, which is the highest stress point in any extension construct.
- **Rod diameter compatibility** spans 5.5 to 6.5mm. Confirm the existing rod diameter before the case. Most Globus systems use 5.5mm rods, but some deformity constructs use 6.0 or 6.35mm.
- **For PJK revisions**, the In-Line Extension Clamp with cranial extension to hooks or screws above the prior UIV is the typical configuration.
- **Keep the set available for any revision of a Globus construct** even if you plan a full revision, as intraoperative findings may favor a limited extension strategy.

## Key Differences vs Competitors

- **vs DePuy Synthes EXPEDIUM revision connectors:** DePuy offers rod-to-rod and lateral connectors within the EXPEDIUM system but does not have a dedicated revision extension clamp system with integrated extension rods. The Revere Addition clamps provide a mechanically stronger junction at the extension point compared to standard side-loading connectors.
- **vs Medtronic CD HORIZON lateral/revision connectors:** Medtronic provides lateral connectors and rod-to-rod connectors for the CD HORIZON system, but these are general-purpose connectors rather than a purpose-built revision extension platform. The Revere Addition system is designed specifically for revision extension scenarios.
- **vs Stryker Xia 3 revision connectors:** Stryker offers parallel, axial, open, angled, closed, and offset rod-to-rod connectors within the Xia 3 system. These are versatile but not revision-specific. The Revere Addition system's clamp-to-rod radius design is engineered for the high-stress junction zone in extension constructs.
- **Limitation:** This system is Globus-proprietary. It cannot be used to extend constructs from other manufacturers (DePuy, Medtronic, Stryker, etc.). If the existing hardware is not Globus, a full revision with hardware removal is required.
