# Silk Vista

**Manufacturer:** Balt (Balt Extrusion SAS)
**Category:** Flow diverter
**Regulatory:** CE marked Class III (CE0297, MDD 93/42/EEC amended by 2007/47/EC). First CE mark 2020. Not FDA cleared for US market.

## What It Is

Self-expandable intracranial flow diverter for the treatment of intracranial aneurysms. Constructed from 48 braided wires using platinum core nitinol Drawn Filled Tubes (DFT) technology, making the entire device visible under fluoroscopy without additional markers.

Part of the Balt Silk family: SILK+ (original, CE 2012), Silk Vista (CE 2020), and Silk Vista Baby (CE 2018).

## Sizing

Delivery catheter compatibility: 0.021" microcatheter for device diameters up to 5.0 mm unconstrained.

Silk Vista Baby variant is deliverable through a 0.017" catheter for distal vasculature targets.

## Indications

Treatment of intracranial aneurysms via endovascular flow diversion.

## Compatible With

- 0.021" delivery microcatheter (Silk Vista)
- 0.017" delivery microcatheter (Silk Vista Baby)

## Use Notes

- 48 braided wires provide escalating flow diversion compared to the original SILK+
- Platinum core nitinol DFT wires provide full fluoroscopic visibility without radiopaque markers
- Silk Vista Baby is the only flow diverter deliverable through a 0.017" catheter, allowing treatment of aneurysms in the distal vasculature
- Manufactured by Balt Extrusion SAS (France)

## Key Differences vs Competitors

- **Visibility**: Silk Vista uses platinum core DFT wires for full device visibility, whereas Pipeline Flex Shield (Medtronic) uses platinum/tungsten + CoCrNi braid, and FRED X uses separate radiopaque markers.
- **Low-Profile Access**: Silk Vista is compatible with a 0.021" catheter for all sizes up to 5.0 mm. Silk Vista Baby is the only flow diverter deliverable through a 0.017" microcatheter, a smaller profile than any competitor offers for distal targets.
- **Surface Modification**: Silk Vista does not incorporate a surface coating. Pipeline Flex Shield has phosphorylcholine (Shield Technology), FRED X has X Technology, and Surpass Elite has BioStealth Surface.
- **Braid Wire Count**: Silk Vista uses 48 wires. Pipeline Flex uses a variable braid count. Surpass Elite uses 64 wires. FRED uses a dual-layer braid (inner high-density mesh + outer stent).
- **US Market**: Silk Vista is CE-marked only and not available in the United States. Pipeline Flex, FRED X, and Surpass Elite all have PMA approval.
