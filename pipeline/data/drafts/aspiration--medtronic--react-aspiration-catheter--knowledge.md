# React Aspiration Catheter

**Manufacturer:** Medtronic
**Category:** Aspiration catheter

## What It Is

Aspiration catheter featuring coil, braid, and end-to-end nitinol construction for navigating vasculature during acute ischemic stroke procedures. Available in React 68 and React 71 sizes.

## Sizing/Specs

Models: React 68, React 71

## Indications

Aspiration thrombectomy during acute ischemic stroke (AIS) procedures.

## Compatible With

Solitaire X Revascularization Device (combined approach)

## Use Notes

Coil, braid, and nitinol construction provides navigability and support.
