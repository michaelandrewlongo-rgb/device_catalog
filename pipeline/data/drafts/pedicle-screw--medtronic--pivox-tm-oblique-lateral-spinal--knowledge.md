# Pivox Oblique Lateral Spinal System

**Manufacturer:** Medtronic
**Category:** Interbody cage / OLIF system
510(k) K152277 | Class 2 | 2015-11-13

## What It Is

Oblique lumbar interbody fusion (OLIF) cage system. PEEK material, radiolucent with optional integrated plate for anterior column support in an oblique approach. Pivoting inserter accommodates the oblique trajectory without requiring repositioning. Compatible with Mazor robotic guidance for OLIF360 single-position surgery.
