# Cosmos Embolic Coil System (MicroVention/Terumo)

**Manufacturer:** MicroVention, Inc. (Terumo)
**Category:** Embolic coil
**Source:** https://www.terumoneuro.com/products/cosmos

## What It Is

The Cosmos is a detachable platinum embolic coil system from MicroVention/Terumo designed for endovascular embolization of intracranial aneurysms and other vascular lesions. It is part of MicroVention's coil portfolio alongside the HydroCoil/HydroFrame (hydrogel-coated) and HydroSoft/HydroFill lines. The Cosmos is a bare platinum coil system with electrothermal detachment using the V-Grip Detachment Controller and V-Trak delivery pusher, consistent with other MicroVention coil platforms.
