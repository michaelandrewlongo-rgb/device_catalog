# Q Guidance System

**Manufacturer:** Stryker
**Category:** Navigation system

## What It Is

Advanced surgical planning and navigation platform for cranial and spine procedures. Features FP8000 4th-generation camera with full-spectrum active/passive hybrid optical tracking. Only guidance system with proprietary active technology. Dual PC architecture (Real-Time PC tracks patient data independent of Application PC). Two touch screen monitors for inside/outside sterile field control.

## Sizing/Specs

Components: FP8000 camera, camera arm, monitor arm, dual computer system, big and small touch monitors, optional EM field generator for cranial. Castors with brakes.

## Indications

Cranial and spine surgical navigation. Spine Guidance Software is FDA-cleared for pediatric patients age 13+.

## Compatible With

Airo TruCT (seamless integration and auto registration). Cranial Guidance Software with optional EM tracking and Precision Targeting System for brain biopsy. Spine Guidance 5 Software with Copilot.

## Use Notes

Up to 4x faster than StealthStation, up to 16x faster than Excelsius per manufacturer claims. Full-spectrum active/passive hybrid optical tracking enables accurate re-registration using reference points.
