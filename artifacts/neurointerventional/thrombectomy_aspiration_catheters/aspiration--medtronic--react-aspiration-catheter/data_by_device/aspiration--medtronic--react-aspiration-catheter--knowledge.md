# React Aspiration Catheter

**Manufacturer:** Medtronic
**Category:** Aspiration catheter

## What It Is

Aspiration catheter featuring coil, braid, and end-to-end nitinol construction for navigating vasculature during acute ischemic stroke procedures. Available in React 68 and React 71 sizes.

## Sizing/Specs

Models: React 68, React 71

## Indications

Aspiration thrombectomy during acute ischemic stroke (AIS) procedures.

## Compatible With

Solitaire X Revascularization Device (combined approach)

## Use Notes

Coil, braid, and nitinol construction provides navigability and support.

## Key Differences vs Competitors

- **Primary indication specificity**: React is specifically indicated for aspiration thrombectomy during acute ischemic stroke (AIS) procedures, whereas some competitors like Ballast (long sheath), Carrier (delivery catheter), and Hybrid (guidewire) are indicated for general intravascular use or device introduction, not specifically for thrombectomy.
- **Construction and design focus**: React features coil, braid, and end-to-end nitinol construction for navigability and support during stroke procedures, while other aspiration catheters like APRO (stainless-steel and coil plus braid) and Riptide (hydrophilic coating on distal shaft) have different reinforcement materials or coatings.
- **Compatibility with specific devices**: React is noted as compatible with the Solitaire X Revascularization Device for a combined approach, whereas compatibility details for most other devices (Ballast, Carrier, Hybrid, Raptor, Artemis, AXS) are not specified in the provided data.
- **Sizing/model availability**: React is available in React 68 and React 71 sizes, which differs from APRO (APRO 55 and APRO 70) and Raptor (sizing not specified), offering distinct diameter options for clinical selection.
- **Procedure mechanism**: React is designed for aspiration thrombectomy, while the Artemis Neuro Evacuation Device is intended for controlled aspiration of tissue/fluid from the Ventricular System/Cerebrum using a neuroendoscope, and the AXS Universal Aspiration Set's specific aspiration mechanism is not specified.
