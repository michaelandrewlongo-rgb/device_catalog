# APRO Aspiration Catheter

**Manufacturer:** Medtronic
**Category:** Aspiration catheter

## What It Is

Flexible aspiration catheter with stainless-steel and coil plus braid reinforcements designed to remove thrombus. Available in APRO 55 and APRO 70 sizes. Includes Alembic aspiration tubing accessory.

## Sizing/Specs

Models: APRO 55, APRO 70; Alembic aspiration tubing: proximal length 100 inch, distal length 7 inch, proximal/distal ID 0.110 inch

## Indications

Aspiration thrombectomy for removal of thrombus from cerebral vasculature.

## Compatible With

Phenom microcatheters, Solitaire X revascularization device, Alembic aspiration tubing

## Key Differences vs Competitors

- **Primary indication specificity**: APRO is specifically indicated for aspiration thrombectomy in cerebral vasculature, whereas Ballast (long sheath), Carrier (delivery catheter), and Hybrid (guidewire) are for general intravascular introduction/delivery/guidance, and Artemis is for aspiration from the Ventricular System/Cerebrum during neuroendoscopy.
- **Direct aspiration catheter competitors**: Compared to other aspiration catheters in this category, APRO has specified sizes (APRO 55, APRO 70) and includes Alembic aspiration tubing accessory; React Aspiration Catheter has different sizes (React 68, React 71) and emphasizes coil/braid/nitinol construction; Raptor Aspiration Catheter has a more detailed stroke indication specifying vessel segments and requires a compatible aspiration pump; Riptide Aspiration System uses continuous aspiration with a hydrophilic coating and requires the Riptide pump.
- **Compatibility details**: APRO lists specific compatibility with Phenom microcatheters, Solitaire X, and Alembic tubing; React is compatible with Solitaire X for combined approach; Raptor requires a compatible aspiration pump and Balt Aspiration Tubing Set; Riptide requires the Riptide pump and a guide catheter; other devices have no specified compatibility or general use.
- **Sizing/specifications availability**: APRO provides specific model sizes and tubing dimensions; React provides model sizes; Ballast, Carrier, Hybrid, Raptor, Artemis, and AXS Universal Aspiration Set have sizing/specs listed as not specified or require contact.
