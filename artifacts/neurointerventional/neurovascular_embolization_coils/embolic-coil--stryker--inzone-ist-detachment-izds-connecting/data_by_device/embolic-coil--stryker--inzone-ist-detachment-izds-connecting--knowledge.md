# InZone IST Detachment System and IZDS Connecting Cable

**Manufacturer:** Stryker Neurovascular
**Category:** Embolic Coil (Detachment System / Accessory)

FDA 510(k) K251832 | Cleared October 17, 2025 | Class II

## What It Is

The InZone IST Detachment System is a sterile, handheld, single-patient use electrolytic detachment controller designed for use with all Stryker Neurovascular embolization devices. It is used to detach electrolytically-detachable embolization coils (platinum embolization coils) from their delivery wires by applying a low-level electrical current that causes electrolytic dissolution at a defined detachment zone on the delivery wire.

The system supports two detachment modes:
- **Monopolar embolization devices** (e.g., Target coils): Requires the IZDS Connecting Cable and a patient return electrode (off-the-shelf 20 or 22 gauge stainless-steel hypodermic needle inserted subcutaneously at the groin) to complete the circuit. Maximum 12 VDC, 1.0 mA.
- **Bipolar embolization devices**: No cable or patient return electrode required; the delivery wire hypotube provides the current return path. Maximum 28 VDC, 2.4 mA.

The IZDS Connecting Cable (model M00345110250) is a 180 cm ground cable sold separately, used only with monopolar devices.

This 510(k) is a modification of the prior InZone Detachment System (K212455), marketed under the new trade name "InZone IST," with generalized indications for use covering all versions of Stryker Neurovascular embolization devices.

## Indications

The InZone IST Detachment System is intended for use with all versions of Stryker Neurovascular embolization devices in the embolization of intracranial aneurysms and other vascular malformations of the neuro and peripheral vasculature.

## Compatible With

- All Stryker Neurovascular monopolar embolization devices (requires IZDS Connecting Cable, sold separately)
- All Stryker Neurovascular bipolar embolization devices (no cable required)
- Patient return electrode: off-the-shelf 20 or 22 gauge uncoated stainless-steel hypodermic needle (for monopolar mode only)

## Use Notes

The InZone IST is designed for use within the sterile field. The unit powers on automatically when the delivery wire is inserted into the funnel; it powers off when the wire is removed. A 2-minute inactivity timeout puts the unit into sleep mode. Five LED indicators provide real-time feedback: system ready, current flow, cycle complete, low battery, and grounding status. Audible tones confirm power-on, grounding completion, and detachment cycle completion.

For monopolar detachment, grounding must be confirmed (solid amber LED) before the detachment button is pressed. Detachment cycle completes in under 75 seconds (solid green LED, 3 short beeps) or at 75 seconds (blinking green LED, 1 long beep) depending on whether detachment is confirmed by the firmware. For bipolar detachment, firmware assesses detachment likelihood at cycle completion.

The unit is single-patient use and contains no user-serviceable parts.

## Key Differences vs Competitors

- **Detachment mechanism**: The InZone IST uses electrolytic detachment (monopolar or bipolar modes), while Medtronic's Axium coils use mechanical detachment via the Instant Detacher, and Cerenovus systems use hydraulic detachment. HydroCoil Embolic System uses thermal detachment via the V-Grip controller.
- **Compatibility requirements**: For monopolar mode, the InZone IST requires the separate IZDS Connecting Cable and a patient return electrode (20/22 gauge needle), unlike bipolar mode or other systems like Axium which don't require patient grounding.
- **Recall status**: The InZone Detachment System (previous version) has 20 active FDA recalls for expired products, while the InZone IST is a modified version with no specified recalls. Cerenovus systems have 1 active recall for detachment failures.
- **Device type**: The InZone IST is a detachment controller only, while competitors like Target coils, Axium coils, and HydroCoil are the actual embolic implants requiring separate detachment systems.
